# Алексей Тимофеев — сайт-портфолио

Сайт: https://ztim2008.github.io/timofeev-art/

## Как добавить работы
1. Подготовьте два файла: большой (~2000 px по длинной стороне) и превью (~600 px), JPG.
2. Положите их в `img/<раздел>/` — разделы: `grafika`, `karandash`, `kartiny`, `aerografiya`, `akvarel`.
3. В `data/works.js` найдите нужный раздел и добавьте в `works` строку:
```js
{"src":"img/akvarel/a01.jpg","thumb":"img/akvarel/a01_t.jpg","w":1500,"h":2000,"title":"Без названия","year":"1997"}
```
`w`/`h` — размеры большого файла. Пустой раздел автоматически показывает «Скоро».
У раздела можно задать `years`, например `"1996–1998"`.
